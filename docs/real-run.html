Four real agents, four working apps

The first round with actual models in the loop. Every previous run used scripted agents that wrote one hardcoded line of HTML, which proved the substrate but proved nothing about whether a model could drive it. This one answers that.

The tool surface works. All four agents picked a theme, wrote an 11–17KB single-page app, backgrounded a server using the exact pattern from the tool description, verified it with curl, and submitted a health-checked URL. No crashes, no malformed calls, no agent wedged a foreground process. On a small, cheap model.
